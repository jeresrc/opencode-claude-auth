## Follow-up: direct transport repaired

The initial provider-side access diagnosis was too strong and is superseded by the local root cause reproduced below.

OpenCode 2.0.25 supplies `FetchHttpClient.Fetch` in the request execution context. Effect's merged HTTP client context lets that host reference override the fetch supplied when constructing our private executor. An isolated reproduction called the host fetch once and our private fetch zero times. The host therefore bypassed the plugin's existing request preparation and auth recovery.
